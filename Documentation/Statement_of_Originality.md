# Statement of Originality

## Interactive Prototype 1: XR Event Planning

I confirm that this Interactive Prototype 1 submission is my own work, except where external tools, software packages, assets, or AI assistance have been acknowledged below.

The concept, interaction design, prototype decisions, testing plan, testing process, data collection, and evaluation were developed for my DECO2300 project.

External resources were used to support the technical development and visual presentation of the Unity prototype. These resources are acknowledged below.

## AI Acknowledgement

| Tool | How it was used |
|---|---|
| ChatGPT by OpenAI | Used to assist with understanding Unity and XR Interaction Toolkit setup, troubleshooting technical issues, explaining implementation steps, and assisting with drafting and refining C# scripts used in the prototype. All design decisions, implementation choices, testing observations, and final evaluation decisions were reviewed and made by me. |

### Example prompts used

- "Help me implement a physical delete interaction in Unity where furniture can be moved into a Delete Zone."
- "Help me create a lighting lever that changes the brightness of the venue."
- "Help me implement a theme interaction using physical wands and a pedestal in XR."
- "Help me troubleshoot XR Grab Interactable and furniture grabbing in Unity."
- "Help improve the wording and structure of my testing plan without changing my intended meaning."
- "Help organise my testing results based on the data I collected from participants."
